##🍽️ Swiggy Clone – HTML & CSS

This is a front-end clone of Swiggy, built using HTML and CSS, designed to replicate the look and feel of the popular food delivery platform. It is a static project focused on layout, design, and responsiveness.

# 🚀 Features
Responsive homepage design

Header with navigation

Food categories 

Stylish restaurant cards

Cities Available in

Footer with useful links and contact info

# 🛠️ Technologies Used
HTML5

CSS3

Google Font Awesome (for icons)
